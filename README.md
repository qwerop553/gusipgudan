# 99단 🧮

GSAT 수리 대비용 두 자리 곱셈 연습 iOS 앱 (SwiftUI, iOS 17+)

## 기능

- **범위 선택** — 19단(11~19 × 11~19) / 두 자리 × 한 자리 / 두 자리 × 두 자리 / 직접 설정
- **연습하기** — 20문제. 틀린 문제는 다시 섞여 나와요
- **타임어택** — 2분 동안 최대한 많이. 최고 기록 저장
- **💡 풀이 보기** — 모르겠으면 누르면 손으로 푸는 세로셈(필산) 과정과 암산 팁이 나와요
  (본 문제는 오답으로 기록돼서 나중에 다시 나와요)
- **오답 집중** — 틀리거나 풀이 본 문제만 복습
- **곱셈표** — 11~99단 × 1~19, 눌러서 풀이 보기
- **내 기록** — 유형별 정답률과 평균 풀이 시간, 자주 틀리는 문제 TOP 10

## 내 아이폰에 설치하기 (무료)

1. Mac에서 `Gugudan.xcodeproj`를 Xcode 16 이상으로 열기
2. 왼쪽에서 **Gugudan** 프로젝트 → **Signing & Capabilities** → **Team**에 내 Apple ID(Personal Team) 선택
   - 번들 ID 충돌이 나면 `com.qwerop553.gusipgudan` 뒤에 아무 글자나 붙이기
3. 아이폰을 케이블로 연결 → 상단에서 내 아이폰 선택 → ▶︎ 실행
4. 처음 한 번: 아이폰 **설정 → 개인정보 보호 및 보안 → 개발자 모드** 켜고,
   **설정 → 일반 → VPN 및 기기 관리**에서 개발자 앱 신뢰

> 무료 Apple ID로 설치하면 7일마다 Xcode에서 다시 ▶︎ 실행해줘야 해요.
> 기록은 앱을 삭제하지 않는 한 유지돼요.
