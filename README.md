# 99단 🧮

GSAT 수리 대비용 계산 연습 앱. 웹앱(`web/`, `docs/`)과 iOS 앱(`Gugudan/`)이 있어요.

> 나눗셈·퍼센트 연습과 새 암산 요령은 웹앱에만 있어요. iOS 앱은 곱셈만 있어요.

## 웹앱 문제 유형

**곱셈** — 19단, 제곱수, 두 자리 × 한 자리, 두 자리 × 두 자리, 세 자리 × 한 자리, 직접 설정
- 풀이: 세로셈 + 상황에 맞는 암산 요령 (×25, ×11, ×99, 19단 요령, 끝자리 합 10, 100 근처, 합차 공식, 제곱 요령, 반·두 배, 반올림 등)

**나눗셈**
- 세 자리 ÷ 한 자리 · 네 자리 ÷ 두 자리 (나누어떨어짐) — 장제법·몫 어림 풀이
- 어림 나눗셈 — 몫이나 비율을 ±3%(또는 ±1, ±1%p) 안으로 맞히면 정답
- 분수 비교 — 두 분수 중 큰 쪽 고르기 (대각선 곱, 증가율 비교, 기준값 요령)

**퍼센트**
- A의 B%, 몇 %인가, 증감률, 증감 후 값, 역산, 연속 증감
- 뒤집기 — A의 B% = B의 A% (50의 8% = 8의 50% = 4)
- 분수 → % — 13/20 = 65%
- %p와 % — 20% → 25%는 5%p 증가, 25% 증가

모든 유형은 💡 풀이 보기로 손계산 과정을 볼 수 있어요. 문제 엔진 검사: `node web/test/engine.test.js`

## 웹앱으로 쓰기 (Mac 필요 없음, 추천)

같은 기능을 웹앱으로도 만들어 뒀어요 (`docs/`). GitHub Pages로 켜면 아이폰 홈 화면에 앱처럼 설치할 수 있어요.

1. GitHub 저장소 → **Settings → Pages**
2. **Source: Deploy from a branch**, **Branch: `main` / `/docs`** 선택 → Save
3. 1~2분 뒤 `https://qwerop553.github.io/gusipgudan/` 열림
4. 아이폰 **Safari**로 열기 → 공유 버튼 → **홈 화면에 추가**

한 번 열고 나면 오프라인에서도 돼요. 기록은 그 폰의 Safari에 저장돼요.

웹앱을 수정할 때는 `web/app.html`을 고친 뒤 `python3 web/build.py`로 `docs/`를 다시 만들어요.

## iOS 네이티브 앱으로 설치하기 (Mac 필요)

1. Mac에서 `Gugudan.xcodeproj`를 Xcode 16 이상으로 열기
2. 왼쪽에서 **Gugudan** 프로젝트 → **Signing & Capabilities** → **Team**에 내 Apple ID(Personal Team) 선택
   - 번들 ID 충돌이 나면 `com.qwerop553.gusipgudan` 뒤에 아무 글자나 붙이기
3. 아이폰을 케이블로 연결 → 상단에서 내 아이폰 선택 → ▶︎ 실행
4. 처음 한 번: 아이폰 **설정 → 개인정보 보호 및 보안 → 개발자 모드** 켜고,
   **설정 → 일반 → VPN 및 기기 관리**에서 개발자 앱 신뢰

> 무료 Apple ID로 설치하면 7일마다 Xcode에서 다시 ▶︎ 실행해줘야 해요.
> 기록은 앱을 삭제하지 않는 한 유지돼요.
