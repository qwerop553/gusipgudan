# 구구단 🧮

나만 쓰는 구구단 연습 iOS 앱 (SwiftUI, iOS 17+)

## 기능

- **단 선택** — 2~9단 중 원하는 단만 골라 연습 (선택은 저장됨)
- **연습하기** — 20문제. 자주 틀리는 문제가 더 자주 나와요
- **타임어택** — 60초 동안 최대한 많이. 최고 기록 저장
- **오답 집중** — 약한 문제만 골라 복습 (4번쯤 연속으로 맞히면 졸업)
- **구구단표** — 전체 표, 자주 틀리는 문제는 빨간색
- **내 기록** — 단별 정답률, 자주 틀리는 문제 TOP 10
- 큰 숫자 키패드, 정답/오답 햅틱, 연속 정답 🔥 표시, 다크 모드 지원

## 내 아이폰에 설치하기 (무료)

1. Mac에서 `Gugudan.xcodeproj`를 Xcode 16 이상으로 열기
2. 왼쪽에서 **Gugudan** 프로젝트 → **Signing & Capabilities** → **Team**에 내 Apple ID(Personal Team) 선택
   - 번들 ID 충돌이 나면 `com.qwerop553.gusipgudan` 뒤에 아무 글자나 붙이기
3. 아이폰을 케이블로 연결 → 상단에서 내 아이폰 선택 → ▶︎ 실행
4. 처음 한 번: 아이폰 **설정 → 일반 → VPN 및 기기 관리**에서 개발자 앱 신뢰
   (iOS 16+는 **설정 → 개인정보 보호 및 보안 → 개발자 모드** 켜기도 필요)

> 무료 Apple ID로 설치하면 7일마다 Xcode에서 다시 ▶︎ 실행해줘야 해요.
> 기록은 앱 안에 저장되어 있어서 재설치해도(앱을 삭제하지 않는 한) 유지돼요.
